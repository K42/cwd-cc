# Kreator Postaci - Cień Władcy Demonów

Postać, którą stworzysz, zapisuje się lokalnie w przeglądarce (przycisk
  "Zapisz postać" w ostatnim kroku) oraz można ją wyeksportować do pliku
  JSON ("Eksportuj do JSON") - to dobry sposób na zachowanie postaci na
  zawsze lub przeniesienie jej na inny komputer.

Do wczytania czcionek aplikacja korzysta z Google Fonts przez internet -
  bez połączenia z internetem aplikacja nadal działa, tylko z domyślną
  czcionką systemową.
